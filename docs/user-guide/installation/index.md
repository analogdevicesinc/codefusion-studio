# Installation

To install and set up CodeFusion Studio for [supported processors](../about/supported-processors.md), complete the following steps:

1. Review the [software requirements](software-requirements.md) and install VS Code.
2. [Run the CodeFusion Studio SDK installer](install-cfs.md). Follow the prompts to complete setup.
3. [Install the VS Code extension](install-extensions.md) to integrate CodeFusion Studio into VS Code.
4. [Set the SDK path](set-up-cfs.md) so the extension can find your CFS SDK installation.
5. Use the [Package Manager](./package-manager/index.md) to install the toolchains, SDKs, and other components.
