# 2.3.0 Release Notes

## Source

CodeFusion Studio source can be found on [:octicons-link-external-24: GitHub](https://github.com/analogdevicesinc/codefusion-studio/releases/tag/V2.3.0/){:target="_blank"} under tag `V2.3.0`

## About this release

CodeFusion Studio 2.3.0 expands *AI-assisted embedded development*. A new Model Zoo helps you discover and deploy models. Documentation-backed AI assistant skills answer product questions directly in your editor. Zephelin profiling now captures traces over USB as well as UART, giving deeper insight into AI inference performance on hardware.

This release also includes a graphical Package Manager that puts browsing, filtering, and installing packages in one place, alongside workspace template expansion and usability improvements across the Workspace Creation Wizard, System Planner, and debug tools.

- **Quick Access Panel:** The CFS sidebar now includes a **Help and Support** section with links to the Getting Started walkthrough, online documentation, Engineer Zone, and technical support.

- **Workspace Creation Wizard — template usability improvements:**
    - Templates in the **Workspace Template** section of the **Workspace Creation Options** step are now listed in alphabetical order.
    - A search bar lets you filter templates by name or description, making it faster to find the right starting point.

- **[Peripheral Allocation](../user-guide/tools/peripheral-allocation.md) — automatic signal assignment:**
    When you allocate a peripheral to a project, CFS automatically assigns each required signal (if it has a single possible pin), reducing manual setup.

- **[Memory Viewer](../user-guide/debugging/debug-tools/memory-viewer/index.md) — go to symbol:** The **Go to** field now accepts symbol names in addition to hex and decimal addresses. Enter a variable or function name to jump directly to its location in memory without looking up the address first.

- **[Package Manager UI](../user-guide/installation/package-manager/manage-packages-ide.md) — new graphical package management:**
    A new graphical interface for managing packages directly in VS Code. Browse and filter packages by name, status, SoC, or type; view package details including version history, license, and supported processors; and install or uninstall packages - all without leaving the editor. Open it by clicking **Manage Packages** in the **Home** section of the CFS sidebar, or by running **(CFS) Open Package Manager** from the Command Palette.

- **[Telemetry](../user-guide/about/telemetry.md) — expanded usage insights:**
    Anonymous, opt-in telemetry covers System Planner configuration, code generation, build, flash, debug, and artificial intelligence (AI) model workflows. Telemetry remains **disabled by default** and collects no personally identifying information.

    Enabling telemetry is one of the most direct ways to influence what we build next — it tells us which features matter most so we can prioritize them. If you'd like to help shape the roadmap, you can turn it on at any time in **Settings** by searching for `cfs.telemetry`. For more information about what is collected, view [Telemetry](../user-guide/about/telemetry.md).

- **[API key authentication](../user-guide/cfsutil/apikey-auth.md) for `cfsutil`:**
    CLI commands that access restricted cloud resources — including `catalog update`, `ai build`, `docker pull`, and package manager commands — can now authenticate using an API key. Set the `CFS_API_KEY` environment variable to your key value before running a command. This is particularly useful in CI/CD pipelines and other automated workflows where interactive login is not possible.

    Use the following commands under the `cfsutil myanalog apikey` topic to create and manage API keys. These commands require an active myAnalog session:

    | Command | Description |
    | --- | --- |
    | `cfsutil myanalog apikey create` | Creates a new API key. |
    | `cfsutil myanalog apikey list` | Lists all API keys for your account. |
    | `cfsutil myanalog apikey delete <key-id>` | Deletes an API key by ID. |

- **[Registers-Only Plugin](../user-guide/workspaces/create-new-workspace.md) deprecated:**
    The Registers-Only (bare-metal) Plugin is deprecated and will be removed in a future release. It remains available in this release for advanced workflows that generate code accessing memory-mapped registers (MMRs) directly.

- **[AI-Assisted Development Skills](../user-guide/developer-tools/cfs-ai-skills.md) — doc-backed answers in your AI assistant:** New `cfs-docs` and `cfs-cli` skills give your AI assistant product-specific answers about CodeFusion Studio. They are bundled with the VS Code extension for GitHub Copilot, and follow the open Agent Skills standard so they also work in Claude Code, OpenAI Codex, and other supported agents.

- **[Model Zoo](../user-guide/tools/manage-ai-models.md#select-a-model-from-the-model-zoo) — browse and select AI models:** When you add a model in the [Embedded AI Tools](../user-guide/tools/manage-ai-models.md) or create a [workspace from an AI model](../user-guide/workspaces/create-workspace-from-ai-model.md), the **Browse** button opens the Model Zoo — a library of AI models hosted by Analog Devices. Search and filter by platform, core, and category, compare model sizes across quantizations, and select a model to populate its file and, when available, sample data fields. You can still select a local model file, or point the Model Zoo at a custom source.

- **[Profiling](../user-guide/tools/profiling.md) — USB trace capture:** Capture Zephelin profiling traces over a USB interface in addition to UART. Select **USB** as the trace interface in System Planner, then select the connected USB device in the Trace Capture panel.

- **Machine-readable documentation (`llms.txt`):** The User Guide is available in an AI-friendly format that follows the [:octicons-link-external-24: llms.txt standard](https://llmstxt.org/){:target="_blank"}. Point your AI assistant at [:octicons-link-external-24: llms.txt](https://developer.analog.com/docs/codefusion-studio/latest/llms.txt){:target="_blank"} for an indexed list of documentation sections, or [:octicons-link-external-24: llms-full.txt](https://developer.analog.com/docs/codefusion-studio/latest/llms-full.txt){:target="_blank"} for the full documentation content in a single file.

- **Build command output:** Build commands display output in a new format. Underlying build behavior is unchanged.

## Known issues and limitations

- **Profiling — USB trace capture on Windows:** USB trace capture does not work reliably on Windows hosts. The device is usually not detected and does not appear in the **USB Device** list, and capture can fail even when the device is detected. Capturing through WSL2 is also unreliable, because USB device sharing is inconsistent. To capture profiling traces over USB, use a macOS or Linux host.
- **Profiling — USB trace capture for run-once applications:** USB capture cannot record traces from applications whose traced activity runs once at startup, including the **Zephyr Single Core TensorFlow AI Inference Profiling** template. Periodic metrics such as **CPU Load** remain available. Use UART to capture run-once traces. See [Profiling](../user-guide/tools/profiling.md#step-4-capture-the-profiler-trace).
- **Profiling — USB trace capture fails to build on MAX78002, MAX32650, and MAX32666:** On MAX78002, MAX32650, and MAX32666 Zephyr projects, selecting **USB** as the trace interface generates code that fails to build, because the High-Speed USB peripheral on these processors is not yet supported in the Zephyr devicetree. The build stops with `warning: The High-Speed USB peripheral is not currently supported in devicetree` followed by `error: '__device_dts_ord_DT_N_NODELABEL_zephyr_udc0_ORD' undeclared`. In this release, USB trace capture is supported on MAX32690 only, and on macOS and Linux hosts only (see the Windows limitation in this section). Use UART to capture profiling traces on MAX78002, MAX32650, and MAX32666. See [Profiling](../user-guide/tools/profiling.md#before-you-start).
- **Profiling — trace capture not supported on MAX32675C:** On MAX32675C Zephyr projects, Zephelin profiling trace capture is not supported over UART or USB.
- **Model Zoo — default catalog coverage:** The Model Zoo displays models from the default catalog for the ADSP-SC835 / SC835W and MAX32690. For other processors, point the Model Zoo at a custom source or select a local model file instead.
- **[Package Manager UI](../user-guide/installation/package-manager/manage-packages-ide.md) — Type filter:** The **Type** filter may not always return the correct package results. To find a specific package, search by name using the search field instead.
